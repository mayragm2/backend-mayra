# ¿Qué es un servidor HTTP y qué hace el módulo http de Node?
Un servidor HTTP es un tipo de servidor que utiliza el protocolo HyperText Transfer Protocol para escuchar requests y devolver un contenido. El módulo http de Node nos permite crear una instancias de servidores o realizar requests HTTP.

# ¿Qué representan req y res en un servidor de Node?
Req y Res representan request y response, es decir pedido y respuesta.

# ¿Qué es un puerto y qué significa que un servidor "escuche" en el 3000?
Un puerto es un punto de comunicacion en el que se puede enviar o recibir información. En este caso le pedimos al servidor que este atento a entradas en el puerto 3000.

# ¿Qué es localhost?
El localhost es el nombre que se le asigna a la computadora propia para poder ejecutar un servidor en la computadora y accederlo desde la misma computadora.

# ¿Qué hace curl y por qué es útil para probar un servidor sin usar el navegador?
Curl realiza un request al servidor y nos devuelve el cuerpo exacto de la respuesta, sin ninguna capa de interpretación de HTML.
